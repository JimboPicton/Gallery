Digital Media Student Gallery

A lightweight static exhibition platform for Creative Media student work. View the public gallery, walk through the 3D exhibition, or manage room layouts and artwork placement using browser-based editors.

Design & Placement Tools

Gallery Layout EditorVisually add rooms, drag them into position, create hallways, add discipline labels, set wall colours/textures, and adjust lighting.Artwork Placement EditorChoose a room and wall, then drag artworks into exact locations. Supports images, video links, YouTube and Echo360 embed/share URLs.

GitHub Pages Workflow

The editors work fully in the browser and export static JSON files. After editing, download the exported gallery-layout.json or gallery-data.json, replace the file in your GitHub repository, then GitHub Pages will publish the updated gallery.

Because GitHub Pages is static hosting, these pages cannot save directly back to the repository unless you later add GitHub API authentication or a backend.
