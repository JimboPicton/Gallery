GitHub Pages Workflow

The editors autosave in this browser. To publish public changes, export the relevant JSON file and replace the matching file in your GitHub repository.

Password-gated galleries in this static version are suitable for draft review and casual access control, but they are not secure private hosting because GitHub Pages serves the files publicly.
