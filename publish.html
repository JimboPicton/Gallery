🚀 Publish Gallery

Use this page when you are ready to package all current local edits. It gathers layout, artwork/media, gallery settings, active gallery information and main-page branding into one publishing workflow.

MainGallery ManagerGallery Layout EditorManage Artwork & MediaArtwork Placement EditorEnter Gallery

1. Select Gallery to Publish

2. Publish Package

For GitHub Pages, this browser cannot commit files for you. These buttons download the files you need to upload/replace in your repository. For the default repository gallery, upload gallery-layout.json and gallery-data.json. The extra settings/registry files are included as a safer backup of the whole editing state.

Recommended workflow: click Download all publish files, then upload/commit the changed JSON files to GitHub. After that, use Mark as Published so reminders clear across the editor screens.

3. Notes

Save Draft keeps changes in this browser. Publish Gallery exports all relevant components together so you are less likely to forget one JSON file. Different browsers will still show different drafts until the exported JSON is uploaded to GitHub and loaded from the repository.
