# Build Notes v9.30.2 - Artwork Viewer and Editor Display Hotfix

## Changes

- Curator metadata actions remain visible at the bottom of the scrolling editor.
- Local-presence and curator-status HUDs hide while the editor panel is open.
- Model display size accepts hundredth-metre increments, including existing values such as 1.85 and 1.9.
- Empty artwork placeholders now open in the same centered media viewer used by populated image artwork.
- Artist labels use a high-resolution 4:1 texture and proportional 3D plane, preventing horizontal stretching.
