# Build Notes v9.28.2 - 3D Curator Artwork Workflow Hotfix

## Included
- Added right-click Edit Metadata in 3D Curator mode for title, artist, description, media type, media URL, thumbnail URL, statement display, and frame size.
- Added existing-gallery-media selection when adding/editing artwork in the 3D gallery.
- Added Fit Frame To Media plus Scale Up/Scale Down actions in the 3D artwork context menu.
- Added Echo360/video thumbnail URL support with a play overlay for non-thumbnailable embeds.
- Added front/back side metadata for half-wall artwork placement and exposed it in artwork/layout editors.
