Entry Experience

How this page fits the workflow

Recommended flow: create/select a gallery, add or edit artwork metadata here, position artwork in the Artwork Placement Editor or use contextual placement in the 3D view, then use Publish to export files for GitHub Pages.

In the 3D view, right-click an artwork for duplicate/delete/light options. Right-click a wall or half wall/partition to add an artwork placeholder at that position.
