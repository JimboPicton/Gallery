Submission Checklist

This checklist uses the same artwork records as artwork-editor.html. Use it to triage work, assign rooms, auto-place groups into usable wall slots, then open the selected item in the placement editor for detailed positioning.

Room assignment and auto-placement

Tick submissions, choose a target room and wall, then assign metadata or auto-place frames across the wall. Auto-placement keeps reasonable spacing and creates curator frame codes for 3D identification.

Gallery Settings

These settings belong with gallery administration rather than spatial layout. They apply to the active gallery and are read by the 3D entry page.

Access

GitHub Pages is static, so password protection is lightweight client-side protection for teaching/showcase use. Private/Draft Only galleries are blocked from the public visitor build.

Entry Experience

Tour Editor

Create curated Presentation Mode tours from the active gallery artworks. Tour data is saved into the active gallery layout and included when you publish.

Use the arrows to reorder stops. Each stop can override the artwork title and narration shown in Presentation Mode.

How this page fits the workflow

Recommended flow: create/select a gallery, add or edit artwork metadata here, position artwork in Artwork Placement or use contextual placement in the 3D view, then use Publish to export files for GitHub Pages.

In the 3D view, right-click an artwork for duplicate/delete/light options. Right-click a wall or half wall/partition to add an artwork placeholder at that position.
