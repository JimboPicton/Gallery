How to Use This Gallery

📸 Adding Images

  1. Use the "Add New Work" tab
  2. Fill in student name, title, and description
  3. Select "Image" as media type
  4. Paste the URL of the image (from Imgur, Cloudinary, etc.)
  5. Add relevant tags and submit

🎬 Adding Videos

  1. Upload video to YouTube, Vimeo, or similar platform
  2. Select "Video" as media type
  3. Paste the direct video URL (not the embed code)
  4. Submit with description and tags

🎨 Adding 3D Models

  1. Upload 3D model to Sketchfab or similar platform
  2. Select "3D Model" as media type
  3. Paste the embed URL (right-click → Copy embed link on Sketchfab)
  4. Submit with details and tags

💾 Saving Your Gallery

  1. All submissions are saved in gallery-data.json
  2. After adding works, commit and push to GitHub
  3. Enable GitHub Pages in repository settings
  4. Gallery will be live at: https://yourusername.github.io/Gallery/
💡 Pro Tip: Use free services like Imgur, Cloudinary, or Sketchfab to host media. This keeps your GitHub repo lightweight!
