# Build Notes – v9.8.5

## Focus
Admin workflow, CQU visual theme, gallery renaming, and contextual artwork actions in the 3D gallery.

## Changes
- Added standard navigation links to `admin.html`.
- Added active gallery picker to `admin.html`.
- Added gallery rename support for local galleries.
- Applied CQU-inspired green/gold UI theme overrides across HTML pages.
- Added 3D right-click context menu for artwork placement and management.
- Added world-positioned artwork support for half walls / partitions.
- Added contextual artwork accent light controls in 3D view.
- Updated `version.json`, README, and visible version labels to v9.8.5.

## Notes
Repository Gallery remains the file-based default and is not renamed from the Admin page. Local galleries can be renamed through the new Admin controls.
