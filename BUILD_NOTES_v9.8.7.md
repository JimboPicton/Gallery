# Build Notes – v9.8.7

## Fixes

- Restored proper right-click context behaviour in the Layout Editor.
- Right-clicking empty canvas can add a new room.
- Right-clicking over an existing room can add light, half wall, teleport, or audio source, but not a nested room.
- 3D contextual artwork tools are explicitly available only in draft/preview editor mode.
- Added/clarified 3D right-click options for adding artwork to walls/half walls and duplicating/deleting existing artwork.
- Restored entry splash image and warning/instructions settings in the Layout Editor theme panel.
- Updated GitHub Pages version metadata.

## Notes

Published public gallery visitors should not see the 3D right-click editing tools unless the gallery is opened with draft/preview editing query parameters.
