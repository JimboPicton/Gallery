# Gallery v9.8.3 — Half Wall Interaction Layer Hotfix

## Fixes
- Half Wall creation now works on top of existing rooms.
- While Half Wall mode is active, rooms, portals, hallways, and other nodes no longer steal pointer focus.
- Cursor remains as a crosshair across the usable editor stage during Half Wall placement.
- Existing half walls can now be dragged over/inside rooms.
- Half walls now have pointer-drag behaviour.
- Right-click delete now works for half walls/partitions.

## Notes
- This is an editor interaction-layer fix, not a gallery data migration. Existing gallery data should continue to load.
- Browser extension message-channel warnings are unrelated to the gallery code if no line/function in the gallery script is referenced.
